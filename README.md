# ARIMA-Based Forecasting System for Selected Staple Food Prices in Nigeria

A production-style machine learning project that forecasts staple food prices in Nigeria using ARIMA models and deploys the results with Streamlit.

## Project Structure

```text
data/              Raw and processed datasets
src/               Python source code
models/            Saved ARIMA models
reports/           Figures and forecast outputs
streamlit_app/     Streamlit dashboard
```
